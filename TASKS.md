## Правила работы в Cursor
1. Делать одну небольшую задачу за раз.
2. Сначала просить Cursor изучить существующие файлы и назвать план.
3. Просить изменять только нужные файлы, а не переписывать весь проект.
4. После каждого шага запускать сайт и проверять результат.
5. Исправлять ошибки текущего шага до добавления новой функции.
6. Не отправлять в чат реальные пароли, токены, `DATABASE_URL` или платёжные секреты.
7. После каждого завершённого этапа делать Git commit с понятным сообщением.
